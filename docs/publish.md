# GitHub 发布

目标账号：weiweiyi332-create。仓库名称：codex-bookmarks。许可证：MIT。

本目录已准备为独立发布源，不能把原工具 data 目录或整个工作区上传。

## 首次发布

1. 登录 weiweiyi332-create，在 GitHub 创建公开的 codex-bookmarks 仓库。
2. 如果由 Codex 继续发布，让 Codex 确认当前登录属于 weiweiyi332-create 后上传本发布目录。
3. 手动网页上传时，进入仓库的 Upload files，把本目录里的 README.md、LICENSE、install.py、demo.py、.gitignore，以及 skills、tests、docs 目录上传，保留目录结构。不要上传整个 ZIP 代替源码。
4. 创建 Release，版本可用 v0.2.0，把独立的 codex-bookmarks-v0.2.0.zip 作为下载附件。
5. 下载 Release ZIP，在新的目录解压并按 README 安装，再公开宣传。

## 宣传前核对

仓库确实公开、链接可访问、源码与 ZIP 同版本、录屏仅用虚构演示数据。抖音脚本最后一句在发布完成前使用“准备开源”，完成后再改为“已经开源”。
