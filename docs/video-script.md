# 抖音录屏脚本 · 约 45 秒

使用 `python demo.py --browser` 打开虚构数据；画面角落注明“演示数据”。不拍真实问答、账号信息、终端启动 URL 或 runtime.json。

| 时间 | 画面 | 口播 |
|---|---|---|
| 0–5 秒 | 收藏列表，点开读书笔记 | Codex 里值得保留的回答，收藏以后怎么找？我做了一个本地收藏夹。 |
| 5–15 秒 | 搜索“知识库”，出现结果 | 它能集中阅读原生收藏，搜索问题和完整回答。 |
| 15–25 秒 | 清空搜索，点击“情绪建构论”，切换组内排序 | 同一个主题的回答放在一起，还能按时间或标题排序，连续回看更方便。 |
| 25–35 秒 | 打开整理表单，添加“下周回看”并保存 | 收藏时可以选已有主题或新建主题，之后也能单独修改，还能给回答加笔记。 |
| 35–45 秒 | GitHub README 或仓库名称 | 我已经把它开源了，叫 codex-bookmarks。Windows 本地运行，不需要 API 密钥，安装方法在 README。 |

最后一句“已经开源”仅在仓库确实公开后使用；发布前改为“准备开源”。

标题候选：**我给 Codex 做了一个能搜索、加笔记的收藏夹**。

简介：第三方开源小工具，集中阅读和整理本机 Codex 原生问答书签。关键词归类、全文搜索、个人笔记。MIT 许可证，适合 Windows 本地使用。

不要宣称：官方插件、智能语义分类、所有版本通用、一键定位到具体回答、已经验证原生侧栏入口。
